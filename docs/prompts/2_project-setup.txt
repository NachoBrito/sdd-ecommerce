## 2. Technical Stack & Architectural Architecture

The architecture and tooling decisions documented in [research.md](file:///home/nacho/github/sdd-ecommerce/specs/001-project-setup/research.md) directly fulfill all user requirements:

1. **Language**: Java 25 via explicit Gradle toolchain (`jvmToolchain(25)`).
2. **Build Automation**: Gradle 8.9+ with strict compilation (`-parameters`, `-Werror`, `-Xlint:all`).
3. **Framework**: Micronaut 4.10.1 (latest stable 4.x), using ahead-of-time (AOT) compile-time DI and zero reflection.
4. **Testing Suite**: JUnit 5, Mockito for external mocks, REST Assured for functional HTTP testing.
5. **Local Ephemeral Backing Services**: Micronaut TestResources spinning up MariaDB and RabbitMQ containers automatically during tests.
6. **Messaging & Event-Driven Architecture**: Decoupled domain events via internal `ApplicationEventPublisher` and asynchronous RabbitMQ messaging.
7. **Domain Architecture**: Strict Hexagonal Architecture (Ports and Adapters) isolating `domain` (zero framework dependencies) from `application` (services, AOP) and `infrastructure` (REST controllers, JDBC persistence, messaging).
8. **Architectural Enforcement**: ArchUnit (`HexagonalArchitectureTest`) verifying package layer isolation and failing the build on any illegal dependency.
9. **Code Quality Gates**: Checkstyle (Google Style, `maxWarnings = 0`), PMD (Strict ruleset, `ignoreFailures = false`), and SpotBugs (Max effort, `ignoreFailures = false`) running on every `./gradlew check`.
10. **Commit Standards**: Conventional Commits enforced via git hook and Gradle verification tasks.
11. **Versioning**: Semantic Versioning (`MAJOR.MINOR.PATCH`) tracked in `version.txt`.
12. **Database**: MariaDB relational database.
13. **Database Migrations**: Liquibase managing versioned, rollback-capable changesets (`db.changelog-master.xml`).
14. **Containerization**: Multi-stage Dockerfile based on Eclipse Temurin / GraalVM 25 JRE with non-root security (`USER 10001:10001`) and health check probes.
15. **Observability**: Micrometer with OpenTelemetry HTTP tracing and Prometheus registry emitting high-cardinality trace IDs and metrics.
16. **Micronaut-Native Solutions**: Micronaut Data JDBC (compile-time queries, no Hibernate/JPA), Micronaut Validation (native validator), Java records and Micronaut sourcegen (no Lombok).
17. **AOP for Cross-Cutting Concerns**: Micronaut AOP (`@Around`, `@StructuredLog`, `LoggingInterceptor`) for logging, tracing, and transactions.
